# Supporting inputs retained for Jamali MEF readiness

These files were migrated from earlier repository folders so the MEF research package is self-contained. They are **planning / sample inputs and provenance**, not Jamali interval operating data and not numerical MEF estimates.

| File | Role |
|---|---|
| `ruptl_2025_2034.pdf` | Primary PLN RUPTL planning snapshot (inventory and long-run input audits) |
| `ruptl_historical_sales.csv` | Prior extraction; Jamali annual sales sample |
| `ruptl_historical_generation.csv` | Prior extraction; annual generation context |
| `ruptl_projected_sales.csv` | Prior extraction; planning cross-check |
| `ruptl_projected_generation.csv` | Prior extraction; planning cross-check |
| `ruptl_projected_emissions.csv` | Prior extraction; scenario emissions (not observed MEF) |
| `wayang_windu_monthly_main_meter_2018_2021.csv` | Plant-level monthly sample used in inventory |
| `wayang_windu_daily_examples.csv` | Limited daily examples (not a full interval series) |
| `wayang_windu_sources.csv` | Provenance notes for the Wayang Windu samples |
| `wayang_windu_audit.json` | Access/coverage audit record for those samples |

Byte hashes for the files referenced by audit manifests are unchanged from the pre-migration copies.
